# Contributing to IQwurksPunch

Thank you for your interest in contributing to IQwurksPunch.

IQwurksPunch is an open-source employee time clock and payroll preparation system focused on reliability, simplicity, maintainability, and professional product quality.

All contributions must follow the engineering standards documented in this repository.

---

## Before Contributing

Read the following documents before submitting changes:

- `README.md`
- `docs/Architecture.md`
- `docs/CodingStandards.md`
- `docs/DefinitionOfDone.md`
- `docs/DeveloperGuide.md`
- `CHANGELOG.md`

Contributors are expected to understand the project architecture and follow the existing design patterns.

---

## Development Requirements

Recommended development environment:

- Linux
- PHP 8.5 or newer
- Composer
- SQLite
- Git
- Cron
- SMTP account for email testing

Install PHP dependencies with:

```bash
composer install
