# IQwurksPunch

IQwurksPunch is an open-source employee time clock and payroll system designed for small and medium-sized businesses.

## Features

- Employee punch in/out
- Payroll calculations
- CSV exports
- PDF reports
- Automatic email reports
- Supervisor dashboard
- SQLite database
- Single-computer deployment
- Open-source (MIT)

## Requirements

- Ubuntu Server
- Nginx
- PHP 8.5+
- SQLite
- Composer
