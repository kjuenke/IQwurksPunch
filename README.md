# IQwurksPunch

**Professional Open-Source Employee Time Clock and Payroll Preparation System**

IQwurksPunch is a lightweight, kiosk-based employee time clock designed for organizations that want a reliable, easy-to-use attendance system without recurring subscription fees.

The application is built using PHP, SQLite, and a custom MVC framework. It is intended to run on a single Linux computer or server while providing a modern web interface for administrators and a simple kiosk interface for employees.

---

## Current Features

- Employee management
- PIN-based employee authentication
- Kiosk mode
- Punch In / Punch Out
- Payroll summary reports
- Daily punch reports
- Company settings
- Timezone-aware reporting
- Automatic scheduled payroll email delivery
- Manual payroll email delivery
- Email history and audit log
- Migration system
- Console application
- SQLite database
- Bootstrap administration interface

---
