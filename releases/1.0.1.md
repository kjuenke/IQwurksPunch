# IQwurksPunch 1.0.1

**Release date:** August 19, 2026
**Release type:** Fresh-install and migration compatibility maintenance release

## Status

Version 1.0.1 is the stable maintenance release following Version 1.0.0.

## Starting Baseline

Version 1.0.1 is based on the published Version 1.0.0 release:

```text
Release commit: a984eb2d9b2184e1ee6c8ba88cb86bd7be8e05ec
Release branch: release/1.0.0
Release tag: v1.0.0
```

The Version 1.0.0 production deployment remained unchanged throughout
development and isolated clone validation.

## Maintenance Scope

Version 1.0.1 repairs the fresh-install migration path by:

- Reusing the migration manager when the migration runner prepares its history
  table
- Adding a missing `batch` column to legacy migration-history tables before
  batch queries are executed
- Making migration 001 compatible with a history table already created by the
  runner
- Making migration 004 safe when the `batch` column already exists
- Creating the missing `email_log` table during fresh installation
- Adding an idempotent migration that repairs installed databases without
  deleting or replacing existing email history
- Adding regression coverage for fresh installs, legacy migration tables, and
  existing email history
- Preserving the documented empty `plugins/` extension directory in source
  checkouts so distribution-package planning is not blocked
- Deferring retry-quarantine database initialization until malformed retry
  metadata actually requires it, keeping clean source-checkout tests isolated
  from the application database

## Upgrade Safety

Version 1.0.1 preserves the supported Version 1.0 upgrade safeguards:

- Verify the release archive and published SHA-256 digest before deployment.
- Create and verify a current database backup before changing application
  source or migration state.
- Preserve `config/mail.php`, the active SQLite database, backups, cache,
  exports, logs, and sessions while deploying the new source.
- Keep maintenance mode active while migration 018 is applied.
- Retain matching Version 1.0.0 source and database rollback materials until
  Version 1.0.1 validation is accepted.

development or clone validation.

## Distribution Package

The final release archive is named:

```text
iqwurkspunch-1.0.1.tar.gz
```

Verify the archive with its published SHA-256 digest before installation:

```bash
./iqwurks package:verify \
    --archive=iqwurkspunch-1.0.1.tar.gz \
    --sha256=PUBLISHED_64_CHARACTER_SHA256
```
