# IQwurksPunch 0.5.0

**Release type:** Reporting, payroll documents, and labor-rules release  
**Release date:** July 20, 2026

---

## Overview

Version 0.5 expands IQwurksPunch from a payroll-calculation and operations platform into a complete payroll-preparation workspace.

This release adds date-range reporting, employee and department filtering, professional CSV and PDF payroll documents, printable employee time cards, and a dedicated Labor Rules configuration system.

Payroll calculations now distinguish daily overtime, weekly overtime, and double-time without counting any hours more than once.

---

## Highlights

### Payroll Workspace

The Payroll Workspace provides a centralized interface for preparing payroll reports across a selected date range.

Administrators can:

- Select a report start and end date
- Filter by employee
- Filter by department
- Review report-wide payroll totals
- Review each employee’s daily payroll detail
- Review payroll-week summaries
- Identify incomplete or mismatched punch records
- Export the resulting report to CSV or PDF
- Generate a printable employee time card when one employee is selected

### Configurable Labor Rules

A dedicated Labor Rules administration page now controls:

- Daily overtime threshold
- Weekly overtime threshold
- Double-time threshold
- Sunday or Monday workweek start

Labor Rules is now the authoritative source for these payroll settings.

Company Settings continues to manage:

- Company identity
- Company timezone
- Punch rounding
- Automatic meal deduction
- Paid-break allowance

Legacy overtime and pay-period values remain available only as compatibility fallbacks for existing installations.

### Payroll Hour Classification

Payroll calculations now report these categories independently:

- Regular hours
- Daily overtime hours
- Weekly overtime hours
- Double-time hours
- Total overtime hours
- Premium hours
- Total payable hours

The payroll engine follows these relationships:

```text
Total Overtime = Daily Overtime + Weekly Overtime

Premium Hours = Total Overtime + Double-Time

Payable Hours = Regular + Total Overtime + Double-Time
```

Weekly overtime is applied only to hours that remain classified as regular after daily overtime and double-time calculations.

This prevents daily overtime or double-time from being counted again as weekly overtime.

## Upgrade Notes

Existing installations upgrading to Version 0.5.0 should complete these steps:

1. Pull the Version 0.5.0 source.
2. Install or update Composer dependencies if required.
3. Run all pending database migrations.
4. Open **Settings → Labor Rules**.
5. Confirm the daily overtime threshold.
6. Confirm the weekly overtime threshold.
7. Confirm the double-time threshold.
8. Confirm whether the workweek begins Sunday or Monday.
9. Open **Settings → Company Settings**.
10. Confirm the company timezone.
11. Confirm punch-rounding settings.
12. Confirm meal-deduction settings.
13. Confirm the paid-break allowance.
14. Generate a daily payroll report.
15. Generate a weekly payroll report.
16. Generate a Payroll Workspace report.
17. Verify CSV exports.
18. Verify PDF exports.
19. Generate an employee time card.
20. Send a manual daily payroll email.
21. Run the automated test suite:

```bash
vendor/bin/phpunit
```

Expected result:

```text
OK (28 tests, 116 assertions)
```

No manual database conversion is required beyond the normal migration process.

## Compatibility Notes

Existing Company Settings columns for daily overtime, weekly overtime, and pay-period start have not been removed from the database.

They remain available as compatibility fallbacks. However, values saved under **Settings → Labor Rules** are authoritative for payroll calculations.

Existing routes, payroll pages, email delivery, scheduler behavior, and export download behavior remain compatible.

- Missing-punch resolution workflow

- Payroll adjustment audit workflows
- Automatic database backup
- Database restore workflow
- Application health checks
- Diagnostic `doctor` command

These capabilities remain planned for later releases.
