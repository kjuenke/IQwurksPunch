# IQwurksPunch 1.0.0

**Release date:** August 10, 2026
**Milestone:** Stable Public Release

## Summary

IQwurksPunch 1.0.0 is the stable public release of the self-hosted employee
time clock and payroll-preparation system.

This release builds on Version 0.9.0 installation, upgrade, rollback, recovery,
deployment, and verified-package foundations. Version 1.0 adds controlled
payroll-period lifecycle management, administrator-controlled supervisor
account management, authentication hardening, strengthened payroll and
data-integrity safeguards, expanded tests, and completed production
documentation.

## Payroll Period Management

Version 1.0 adds:

- Payroll-period creation with defined start and end dates
- Overlap validation
- Draft editing
- Separate active and removed period lists
- Protected draft deletion
- Finalized-period archival and voiding with required reasons
- Company-local employee and punch counts
- Report-artifact tracking status
- Explicit destructive-action confirmation
- Payroll-period lifecycle audit history
- Punch retention when payroll-period records are removed

CSV and PDF reports continue to be generated and streamed on demand. They are
not retained as payroll-period-linked artifacts.

## Supervisor User Management

Administrators can:

- Create supervisor accounts
- Edit usernames, email addresses, roles, and status
- Reset passwords
- Activate or deactivate accounts
- Review account activity and last-login information

Version 1.0 protects the final active administrator, prevents an administrator
from disabling their own active session, and records dedicated before-and-after
audit details for role changes.

## Authentication and Session Security

Version 1.0 adds:

- Eight-hour supervisor inactivity expiration
- Session synchronization with current database account state
- CSRF-token rotation after successful login
- Expanded authentication and authorization tests

## Payroll and Data Integrity

Version 1.0:

- Aligns overtime-threshold validation across settings and calculation policy
- Rejects unsupported payroll punch types as incomplete data
- Requires affected rows for successful punch updates and deletions
- Verifies payroll-period deletion does not remove employee punches
- Preserves audit history for administrative lifecycle actions

## Installation and Upgrade

New installations should follow:

```text
docs/Installation.md
```

Upgrades from Version 0.9.0 should use the documented controlled upgrade
workflow, including a fresh verified backup, maintenance mode, package checksum
verification, migration execution, database checks, scheduler checks, and
post-upgrade application validation.

## Distribution Package

The Version 1.0 archive is named:

```text
iqwurkspunch-1.0.0.tar.gz
```

The archive must pass independent verification before publication. Its SHA-256
digest is published alongside the release artifact rather than embedded in this
source release note.

## Current Limitations

Version 1.0 does not include:

- A graphical operating-system installer
- Automatic operating-system or web-service configuration
- Built-in HTTPS provisioning
- Persistent payroll-period-linked report artifacts
- Third-party payroll-provider export profiles
- Multiple-company or multiple-location management
- Multiple independently managed kiosks
- Employee self-service
- Cryptographic package signatures beyond published SHA-256 verification
