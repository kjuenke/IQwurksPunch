# IQwurksPunch 0.3.0

**Release type:** Development platform and reliability release  
**Release date:** July 13, 2026

---

## Overview

Version 0.3 established the platform, reliability, logging, scheduling, documentation, and release-management foundation needed for continued IQwurksPunch development.

Earlier releases concentrated on the employee kiosk, supervisor authentication, employee management, punches, and initial payroll reporting. Version 0.3 focused on making those capabilities easier to operate, diagnose, maintain, and extend.

---

## Highlights

### Application Console

- Added the `iqwurks` console entry point.
- Added reusable console-command architecture.
- Added the scheduled-report command.
- Standardized console exit behavior and output.

### Scheduled Reporting

- Added automatic daily payroll-report scheduling.
- Added cron integration.
- Added company-local scheduling.
- Added duplicate-send prevention.
- Added scheduler file locking.
- Added last-send tracking.

### Logging

- Added centralized logging configuration.
- Added logger interfaces and file handlers.
- Added component-specific log channels.
- Added scheduler lifecycle and diagnostic logging.
- Added mail-delivery logging.
- Separated structured scheduler logs from raw cron output.

### Company Configuration

- Added company timezone management.
- Applied company timezone to reporting.
- Applied company timezone to displayed email history and scheduled-report behavior.

### Documentation and Release Management

- Added the project README.
- Added the changelog and roadmap.
- Added the MIT license.
- Added the Definition of Done.
- Added coding standards.
- Added the contributor guide.
- Established Git commit, branch, and release practices.

---

## Upgrade Notes

Existing development installations should:

1. Pull the Version 0.3 source.
2. Run all database migrations.
3. Verify `config/mail.php`.
4. Verify company timezone settings.
5. Verify the scheduler command manually.
6. Verify cron execution and scheduler logs.
7. Review the updated project documentation.

No manual database conversion is required beyond normal migrations.

---

## Known Limitations at Release

Version 0.3 did not yet include:

- The completed payroll engine
- Weekly payroll
- Employee lifecycle controls
- Database-managed email recipients
- CSV exports
- PDF reports
- Automated backup and restore
- A live operations dashboard

These items were scheduled for later releases.
